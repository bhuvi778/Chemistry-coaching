## 🎯 Start Testing in 3 Steps

### Step 1: Open the Website
```
Navigate to your website homepage
```

### Step 2: Access Flash Cards
```
Click: Navbar → Study Material → Flash Card
OR
Go directly to: /flash-cards
```

### Step 3: Start Practicing!
```
1. Click on "Solutions" chapter (purple flask icon)
2. Select any topics (try "Colligative Properties")
3. Click "Start Practice"
4. Click cards to flip and reveal answers
5. Mark yourself as Correct or Wrong
6. See your results!
```

## 🔧 Admin Panel Access

### To Add/Edit Cards:
```
1. Go to: /admin
2. Login with your credentials
3. Click "Flash Cards" in the sidebar
4. Use the 3 tabs:
   - Chapters: Manage chapters
   - Topics: Manage topics
   - Cards: Manage flashcards
```
