## 🎯 Common Tasks

### Task 1: Add a Video to a Blog
**Documentation**: `HOW_TO_USE_BLOG_VIDEOS_IMAGES.md` → Section: "Adding Videos"

**Quick Steps**:
1. Admin → Manage Blogs → Create/Edit
2. Scroll to "Video URLs"
3. Paste embed URL
4. Press Enter
5. Save blog

---

### Task 2: Add Images to a Blog
**Documentation**: `HOW_TO_USE_BLOG_VIDEOS_IMAGES.md` → Section: "Adding Images"

**Quick Steps**:
1. Admin → Manage Blogs → Create/Edit
2. Scroll to "Additional Images"
3. Click Choose File
4. Select image
5. Wait for upload
6. Repeat for more images
7. Save blog

---

### Task 3: Find Video/Image Sections
**Documentation**: `BLOG_ADMIN_PANEL_VISUAL_GUIDE.md` → Section: "Exact Locations"

**Quick Steps**:
1. Open blog form
2. Look at right column
3. Scroll down
4. Find "Video URLs" (purple)
5. Find "Additional Images" (below videos)

---

### Task 4: Troubleshoot Issues
**Documentation**: `HOW_TO_USE_BLOG_VIDEOS_IMAGES.md` → Section: "Common Issues"

**Quick Steps**:
1. Check error message
2. Verify URL format
3. Check file size
4. Test in browser
5. Clear cache
