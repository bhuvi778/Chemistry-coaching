## 🔄 **User Flow (All Tabs):**

1. **View Questions** - All questions displayed in a list
2. **Select Answer** - Click on an option (highlighted in cyan)
3. **Submit** - Click "Submit Answer" button
4. **Get Feedback** - Instant visual feedback:
   - ✅ Green if correct
   - ❌ Red if incorrect
   - Correct answer always shown in green
5. **View Solution** - Click to see detailed explanation
6. **Track Progress** - See score/completion percentage
7. **Continue** - Move to next question

## 🎯 **Differences (By Design):**

### **Line-by-Line Tab (Extra Features):**
The Line-by-Line tab has some additional features that enhance the learning experience:

1. **Retry Button** - Allows users to try again if they get it wrong
2. **Difficulty Rating** - Users can rate how hard they found the question
3. **Hint System** - Additional hints available before viewing solution
4. **Filters** - Filter questions by difficulty

These extras are **intentional** and provide a more comprehensive learning experience for the detailed line-by-line study.

### **Questions/Exemplars/Diagrams Tabs (Streamlined):**
These tabs have a **cleaner, more focused** quiz interface:
- Direct question practice
- Score tracking
- No extra buttons
- Faster workflow
